# Action layout concepts

Three standalone owner-reviewed composition previews, preserved as six exact HTML/CSS/JS/logo/font/license files. `manifest.json` records each content hash. Local attributes preserve source bytes without Git line-ending conversion; the original font license whitespace is retained verbatim. A: `priority`, B: `strip`, C: `more`.

Public base: https://wallet.153.76.194.160.nip.io/concepts/ — comparison page without a variant; append `?variant=priority`, `?variant=strip` or `?variant=more` to open one example. All links/assets are relative to this directory; no path adaptation was needed.

These are demo compositions with local menus and page-memory settings. No backend, storage, real financial operations or complete product navigation is connected. The light composition is a free interpretation; it does not reproduce every GPU material of MONO. Font license is included in assets/OFL-Manrope.txt.

This directory is a source archive, outside miniapp src/public. Only the six allowlisted static files are uploaded; README/manifest stay in Git. The publication uses an isolated static release and wallet-only Caddy route. Current MONO, seven published presets/history and local runtimes are separate from this release.
