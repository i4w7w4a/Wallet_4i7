# Novex — три направления интерфейса

Интерактивная примерка от 20 октября 2026, подготовленная по запросу владельца на основе публичного Gold. Исходная точка: `29cc41b9d3b3a44e4da56bc2704cf1508594c4d8`, ветка `codex/gold-ci-release-20261018`; app SOURCE релиза — `7d097c9cc6e1286297315c78520f341a364b35f0`.

## Открыть и сравнить

Приватная тестовая версия для владельца: [Novex — три направления](https://novex-ux-directions-20261020.royal-kiwi-6545.chatgpt.site).

В левой панели выберите композицию:

1. **A / Тихий обзор.** Баланс в свободном поле, четыре компактных действия, одна строка средств. Рекомендуемый старт для запроса на спокойствие.
2. **B / Два действия.** «Отправить» и «Получить» образуют ведущую пару; «Обмен» и «Купить» остаются видимыми ниже.
3. **C / Единая карточка.** Баланс и четыре действия объединены одной поверхностью.

Клавиши `1`, `2`, `3` переключают композиции вне полей ввода и открытого диалога. Адрес поддерживает `?variant=a|b|c&width=320|390|430|480`. Ширина — реальный размер контейнера; на узком экране она ограничивается доступным местом. Во всех вариантах один state, одинаковый портфель и одинаковые сценарии.

## Что работает

- Обзор, активы, карточка актива и размещения по сетям.
- История с поиском, фильтрами по статусу/направлению и inline-квитанцией.
- Единое скрытие сумм, включая доступные подписи и детали операций.
- Меню, вложенные счета, профиль, настройки, локальная помощь.
- Четыре действия: ввод, проверка данных, завершение примерки; выбор актива и сети в отправке/получении.
- Черновики и фильтры сохраняются при переключении композиций и до перезагрузки страницы.
- Нажатие 80 ms, возврат 190 ms, конечные переходы; ручное и системное отключение движения.
- Native dialog, Escape, возврат фокуса, видимый keyboard focus, сброс поиска с фокусом в поле.

Отправка принимает только демонстрационные получатели вида `demo:имя`. Получение показывает выбранную сеть, но не создаёт платёжный адрес или QR-код. Обмен и покупка используют явно подписанные фиксированные примеры. Действия не меняют портфель или историю.

## Состав и запуск

Runtime состоит из `index.html`, `styles.css`, `app.js` и `assets/`. Нет сборки или runtime-зависимостей. Для локальной работы раздайте каталог обычным статическим HTTP-сервером, например:

```bash
python -m http.server 8080 --directory prototypes/wallet-ux-lab
```

Это самостоятельный source-каталог вне `miniapp/src/public`; он не регистрирует новый Next route. На публичном сервере Novex маршрут к нему не создавался. Примерка размещена на отдельном owner-private Site. Production Gold, общий product controller, финансовые команды, MONO, семь presets и renderer не изменены.

## Происхождение материалов

- `assets/logo.svg` — неизменённый `apps/miniapp/public/brand/novex-logo.svg`; тёплый монохромный тон задаёт presentation CSS.
- `assets/manrope.woff2` и `OFL-Manrope.txt` — из существующего `prototypes/action-layouts/assets/`; шрифт загружается локально.
- Портрет — существующий `apps/miniapp/public/media/mono/profile/demo-portrait-v1.webp`; пояснение сохранено в `portrait-source.md`.
- BTC, ETH, USDC — существующие currency logos; сохранены лицензия и provenance.
- SVG действий и навигации используют stroke grammar `packages/ui/src/icons/wallet-icon.tsx` с несколькими простыми локальными значками.
- Числа и размещения — `packages/core/src/wallet-product-demo.ts`; четыре даты, направления и статуса истории — `apps/miniapp/src/mono-product/demo-activity.ts`.

Новые изображения, внешние шрифты, пакеты или сетевые API не добавлялись. SHA-256 runtime-файлов записаны в `manifest.json`.
