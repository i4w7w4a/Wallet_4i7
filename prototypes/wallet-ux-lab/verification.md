# Проверка интерактивной примерки

20 октября 2026. Проверялся самостоятельный `prototypes/wallet-ux-lab` в Chrome через управляемый статический preview. Результаты относятся к этому прототипу, а не к production Gold.

## Пройдено

| Проверка | Наблюдаемый результат |
|---|---|
| A/B/C × 320/390/430/480 px | Все 12 сочетаний Home без горизонтального переполнения; измерена реальная ширина DOM-контейнера. |
| Размеры Home controls | Все видимые кнопки кошелька ≥44×44 CSS px. После увеличения кеглей повторён самый узкий размер 320 во всех трёх композициях. |
| Активы и USDC | Список и карточка открываются; 500 USDC Ethereum и 400 USDC Solana показаны отдельно; на 320 px переполнения не обнаружено. |
| Пустой поиск | По запросу без совпадений показан empty state; reset восстановил четыре операции и вернул фокус в `history-search`. |
| Смена варианта из History | Запрос `USDC`, две соответствующие операции и активный раздел сохранились. |
| Inline-квитанция и privacy | Ожидающая операция раскрывается. После скрытия сумм цифры заменены и в строке, и в квитанции, и в accessible name. |
| Send | 600 USDC на Ethereum отклонены с фокусом на сумме; 12,5 прошли к проверке и завершению демо. |
| Черновик | Ввод 25,75, закрытие, смена варианта, повторное открытие — значение сохранено. |
| Receive | USDC → Solana → реквизиты демо: выбранная сеть сохранена, платёжный адрес не создаётся. |
| Swap | 10 USDC показаны вместе с рассчитанной стороной ETH; фиксированный характер расчёта подписан. |
| Buy | 100 USD показаны на проверке вместе с примером получения 100 USDC. |
| Escape | Диалог закрывается; фокус возвращается на кнопку «Отправить». |
| Меню → счета → активы | Переход выполняется после native close; конечный раздел — assets. |
| Motion toggle | В отключённом режиме computed transition duration = 0s и animation name = none. Во включённом режиме возврат action-icon = 190 ms. |
| Код | `node --check app.js`; `git diff --cached --check`. |

Независимая проверка исходника дополнительно проверила экранирование ввода, допустимые URL-параметры, отсутствие финансовых API и сохранения черновиков в storage. Вторичный текст светлой панели приведён к контрасту ≥4,5:1 относительно базового фона; границы полей усилены. Это точечные измерения цветов, не заявление о полной сертификации WCAG.

## Найдено и исправлено в примерке

- Несогласованные HTML/CSS классы, исходные стили заголовков и списков.
- Недостаточный контраст вторичного текста лабораторной панели.
- Размер кнопок выбора ширины меньше 44 px.
- Тесная компоновка поиска и фильтров на 320 px.
- Сброс прокрутки самого dialog при переходе формы к проверке.
- Возврат фокуса при переходе из счетов в активы.
- Маскировка доступного лимита в ошибке обмена при скрытых суммах.
- Связь подсказок формы с полями через `aria-describedby`.
- Отключение смещения стрелки ожидающей операции в reduced motion.
- Привязка нижней границы диалогов к видимой области кошелька.

## Пределы проверки

- Проверены реальные контейнерные ширины, а не отдельные физические телефоны; iOS Safari и Android Chrome не запускались.
- Ручной переключатель уменьшения движения проверен в браузере. Системный `prefers-reduced-motion` реализован и просмотрен в коде, но настройки ОС в этой сессии не менялись.
- Проверка screen reader отдельным ассистивным приложением и пользовательское исследование A/B/C не проводились.
- Котировки, комиссии, отправка в сеть, платёжные провайдеры и восстановление кошелька не входят в прототип.
- Next build и финансовые suites не запускались: каталоги приложения, зависимости и production runtime не изменялись. Исторический релизный full suite с baseline failures не объявляется повторно зелёным.
- Скриншоты трёх вариантов сохранены вместе с исходником отдельного тестового Site. Точность визуального выбора оценивается владельцем по интерактивной версии.
