# Novex Wallet

Демонстрационный мобильный кошелёк и лаборатория внешнего вида MONO/V2. Сейчас основная продуктовая линия — [`/mono`](https://wallet.135.181.70.158.nip.io/mono). Маршрут `/` сохраняет промежуточную V1 для сравнения; он не является новой версией MONO.

Это визуальный прототип с демонстрационными данными, а не сервис для хранения средств или проведения реальных операций. На временном хостинге рабочие пресеты сохраняются локально в браузере. Серверная библиотека пресетов намеренно недоступна (`503`) до отдельной проверки PostgreSQL, безопасности и восстановления из резервной копии.

## Локальный запуск

Нужны Node.js 24+ и pnpm 10.33.2.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Откройте `http://localhost:3000/mono`. Для проверки поддержанных ширин используйте переключатель `320 / 390 / 430 / 480` в лаборатории; вся сцена не уменьшается через `scale`.

## Проверки

```sh
pnpm test
pnpm typecheck
pnpm lint
pnpm build
pnpm --filter @wallet/miniapp exec playwright install chromium
pnpm --filter @wallet/miniapp exec playwright test e2e/mono-
```

Визуальные эталоны не обновляются автоматически: изменение изображения требует просмотра владельцем.

## Карта проекта

- `apps/miniapp` — Next.js-приложение, маршруты `/` и `/mono`;
- `packages/core`, `packages/platform`, `packages/ui` — данные, интеграции и интерфейс;
- [`docs/skins/README.md`](docs/skins/README.md) — текущий MONO/V2 и границы лаборатории;
- [`docs/deployment/TEMPORARY-PREVIEW.md`](docs/deployment/TEMPORARY-PREVIEW.md) — безопасное обновление временного адреса и откат;
- [`docs/deployment/README.md`](docs/deployment/README.md) — полный runbook, включая архивные планы для домена, которым проект не владеет;
- [`AGENTS.md`](AGENTS.md) — правила для работы с кодом.

Переименование репозитория не меняет внутренние package IDs, старые имена в исторических документах и ключи `wallet4i7.*` в `localStorage`. Они сохранены ради совместимости с пользовательскими данными. Открытые старые Issues и Draft PR не означают, что V1 снова стала основной линией; их разбор будет отдельным этапом.

Текущая MONO-линия публикуется отдельной веткой по умолчанию. Исторический `main` и открытые Draft PR сохраняются без переписывания истории и будут разобраны отдельно.
