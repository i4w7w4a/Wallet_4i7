# Novex Wallet

Интерактивный прототип мобильного кошелька и лаборатория оформления MONO. Этот README — вход в актуальное состояние; подробные контракты находятся в технической карте ниже.

## Что можно посмотреть

- Публичный прототип показывает счета, активы, получение/отправку и историю на демоданных.
- Покупка и обмен собраны и проверены в локальном демо; публично пока не выпущены.
- Аватар и быстрые настройки темы, скрытия сумм и помощи готовы в локальной примерке.
- Окончательная визуальная оценка новых локальных изменений ещё предстоит.
- Три опубликованные компоновки действий сохранены для обсуждения; вариант пока не выбран.
- Реальные операции и финансовые правила требуют отдельного backend-контракта.

## Разработка

Node.js 24+, pnpm 10.33.2. Для отдельного clone:

~~~sh
pnpm install --frozen-lockfile
pnpm dev
~~~

В общей рабочей копии текущим production-preview управляет ORACLE; новый сервер не запускается автоматически. Проверки выбираются по изменённому поведению, общий build — на принятом интегрированном source. Успех тестов или сборки не означает визуальной приёмки; эталоны не обновляются автоматически.

Имена packages и versioned ключи `wallet4i7.*` сохраняются ради совместимости. `/` и старые V1/Draft PR — историческая линия; их наличие не меняет основную MONO. Старые handoff и runbook не являются новым разрешением на deploy.
