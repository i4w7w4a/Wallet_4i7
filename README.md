# Novex Wallet

React-фронтенд мобильного кошелька с двумя направлениями оформления: Gold и MONO. Счета, активы, получение, отправка, внутренний перевод, обмен, покупка, история, профиль и поддержка собраны в демонстрационные сценарии. Реальные финансовые операции и backend пока не подключены.

## Посмотреть

- [Gold — клиентская версия](https://wallet.153.76.194.160.nip.io/gold)
- [MONO — рабочая сцена и лаборатория](https://wallet.153.76.194.160.nip.io/mono)
- [Пример visitor-ссылки без редактора](https://wallet.153.76.194.160.nip.io/p/2)
- [Отдельная примерка буста перевода](https://wallet.153.76.194.160.nip.io/concepts/boost-preview/)

Семь сохранённых оформлений доступны по постоянным адресам `/p/1`–`/p/7`. Gold — отдельное представление кошелька. Корневой вход публичного сайта ведёт в MONO; прежняя V1 больше не основной вход.

## Локальный запуск

Node.js 24+ и pnpm 10.33.2.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Откройте `http://localhost:3000/gold` для полного Gold или `http://localhost:3000/mono` для MONO. Поддерживаемые ширины сцены — `320 / 390 / 430 / 480` CSS px, без уменьшения всего приложения через scale. Новая локальная сборка имеет собственные Git SHA и BUILD_ID: публичный сайт продолжает работать на ранее выпущенном артефакте.

## Проверки

Проверять изменённый сценарий и затронутые контракты. Перед общим выпуском — один интеграционный проход; повторять широкие проверки только при новой причине.

```sh
pnpm test
pnpm typecheck
pnpm lint
pnpm build
```

E2E запускаются отдельно по затронутым сценариям. Новые визуальные эталоны требуют просмотра владельцем.
