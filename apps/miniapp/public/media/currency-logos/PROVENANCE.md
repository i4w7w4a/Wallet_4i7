The upstream SVGs have no final newline. `apply_patch` added one final LF to
each local copy; the artwork, paths, fills and original 32×32 viewBox are
unchanged. Repository checkout newline conversion may change working-copy
hashes; the local hashes above describe the LF files committed to Git.
Upstream artwork totals 2,932 bytes; the local copies total 2,935 bytes.

The upstream [LICENSE.md](https://raw.githubusercontent.com/spothq/cryptocurrency-icons/1a63530be6e374711a8554f31b17e4cb92c25fa5/LICENSE.md)
is 7,048 bytes. Its source and local SHA-256 are both
`A2010F343487D3F7618AFFE54F789F5487602331C0A8D03F49E9A7C547CF0499`.

The retrieved SVGs contain only `svg`, `g`, `circle` and `path` elements, with
no scripts, event handlers, `foreignObject`, embedded images, `use`, external
references or runtime dependencies. Logos are served as decorative local
images. The allowlist maps `btc`, `eth` and `usdc` asset IDs; network labels and
route identity remain independent. Both USDC networks use the same SVG.

The selection followed the coordinator's comparison of this compact,
consistent CC0 set with the larger MIT `0xa3k5/web3icons` collection and direct
Ethereum/Circle brand kits with different terms. No package or runtime CDN
was introduced.
