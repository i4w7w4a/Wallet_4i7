# Мастерские: видимая сцена и применение в MONO

2026-09-25. Актуальный task packet по замечаниям владельца к опубликованным мастерским. База — `02663577b3f3b9e4175f8398987070f830a87e0f`, `codex/mono-material-workshops`. Это продолжение существующей работы, не новая версия кошелька.

Владелец отдельно подтвердил: «Применить» должно переносить настроенные кнопки/фон в выбранный рабочий пресет MONO. Прежний запрет на продуктовую интеграцию снимается только для этого явного переноса. Автоматическая публикация пресетов, новое облако и перенос всех лабораторных черновиков не разрешены.

## Воспроизведённая проблема

На публичных `/design-lab/buttons` и `/design-lab/atmosphere` длинный инспектор увеличивает высоту документа. Прокрутка над параметрами уводит сцену выше экрана. В фоне это воспроизведено при открытых «Цвет» и «Физика», в кнопках — уже на нижних параметрах кромки. Это ошибка компоновки, а не доказанный отказ WebGL.

Кроме того, на высоте 712 px настоящие быстрые действия MONO находятся ниже первого экрана. Простого закрепления верхней части телефона недостаточно.

## Рабочее место

- Одна компактная верхняя строка: вход в Lab/другую мастерскую, имя/статус, действия с пробой. Без второй высокой навигации и дублирующего заголовка.
- Слева: материал или целевая кнопка, варианты/слоты, формат и ширина сцены.
- По центру: видимая сцена в доступной высоте окна. Канонические ширины 320/390/430/480 — настоящие CSS widths, без scale.
- Справа: слой кнопки и параметры материала; компактные иконки групп с подсказками, раскрытие по запросу. Длинные пояснения не занимают постоянное место.
- Левая и правая панели прокручиваются независимо. Document не растёт от раскрытия параметров. Прокрутка самого кошелька остаётся отдельной.
- В кнопочной мастерской при начальном входе/смене цели виден настоящий редактируемый action row. Есть компактная команда возврата к нему; каждый сдвиг slider не перезапускает автопрокрутку.
- Визуальные glyph небольшие, но область нажатия не меньше 44×44. Tooltip доступен при hover и focus. Ползунки сохраняют точный числовой ввод и клавиатуру.
- Узкий экран использует согласованный паттерн панелей MONO: взаимоисключение, Escape, focus return, закрытая панель inert. Открытие вложенного диалога не создаёт два конкурирующих focus trap.

## Значения действий

| Действие | Результат |
| --- | --- |
| Изменение параметра | Немедленная примерка в этой мастерской |
| Сохранить пробу | Именованный вариант в отдельной локальной библиотеке мастерской |
| Принять/отменить лабораторную примерку | Существующий локальный accepted state / Cancel; не выдаётся за изменение MONO |
| Применить в MONO | Явно выбранный рабочий пресет и направление получают только выбранный scope материала |
| Дополнительно `⋯` | JSON, импорт/экспорт, копирование между мастерскими, источник, диагностика |

Имя пробы вводится после команды сохранения. Для применения в MONO не требуются экспорт JSON или предварительное именованное сохранение пробы. Видно имя получателя и результат записи; после успеха доступен прямой переход в MONO.

Перенос не должен стирать logo, palette, typography, geometry, optics, layout, motion, чужой материал или другие направления. Полный нормализованный snapshot материала копируется, не связывается с будущими edits лабораторного draft. Сохранение в рабочий пресет и отправка на сервер остаются разными операциями. Ошибка quota, несовместимость, stale revision или конфликт не дают ложного «Применено».

## Владельцы

Все исполнители — GPT-6 Sol / Max, существующие задачи и отдельные worktrees от указанной базы.

| Владелец | Единоличная область |
| --- | --- |
| M5, `01a0d216-ff4d-7b90-8bbc-8b63a3c422b9` | Новый общий `material-workbench` shell, `material-controls/**`, atmosphere UI |
| M6, `01a0d663-dd5a-7503-adbc-ff7775492254` | Buttons UI/scene focus; потребитель shell и Apply bridge, без их параллельного редактирования |
| ORACLE, `01a0cfcc-f35e-7a50-a624-6dda3022b4fb` | Preset bridge/codec, MONO и view rendering, shared GPU, маршруты, интеграция и release |
| Координатор | Scope, воспроизведение, независимый просмотр единой сборки, этот packet |

M5 сообщает shell API M6 и ORACLE до полного handoff; ORACLE сообщает Apply API обоим. Общие файлы не редактируются параллельно. Авторы передают только свои commits, не сливают целиком старые ветки.

## Короткая приёмка

1. 1440×900 и 1366×768: открыть длинные группы, долистать обе панели до конца, изменить нижний slider. Сцена и редактируемые кнопки остаются видны; document scrollY не меняется.
2. 320/390/430/480: без горизонтального overflow; настоящие размеры сцены, клавиатура, focus, Escape, Save/import dialogs работают.
3. Старые сохранённые пробы открываются; slots, Undo/Redo, A/B, Save/reload, Cancel, import/export не потеряны.
4. Применить фон, затем кнопки в один выбранный рабочий пресет. Переключиться на другой, вернуться, перезагрузить — оба материала и остальные поля сохранены. Повторное изменение лабораторной пробы не меняет пресет само.
5. Проверить actual rendered MONO и сохранение через существующие export/share/view либо явно отклонить неподдерживаемый payload. Нельзя молча потерять новые поля в строгом старом codec.
6. Один canvas/context/host RAF, approved Promo без изменений; реальные GPU-иконки с контуром, guards и resource budgets остаются. Не менять физику эффектов ради перестановки панелей.

Один общий preview и один согласованный browser/build slot. После проверки координатором — один scoped commit/candidate и прежний безопасный release-путь на wallet host с rollback. Без самостоятельного merge, переписывания default branch, V1, DNS, Caddy, admin или базы данных. PR403 остаётся отдельным ограничением доступа и не обходится другой учёткой. Финальный handoff содержит действующие ссылки, полный SHA и честный статус GitHub/deployment.
