## Task 1: Реализовать единую Gold Home

### Global Constraints

- Только Gold presentation и необходимые Gold-only host переходы. MONO, `/p/1`–`/p/7`, профиль/session, опубликованные snapshots, финансовый controller/ports, approved assets/materials и liquid renderer не изменять по поведению.

- Общая USD-оценка не становится доступным остатком отправки. Конкретный route требует account/asset/network и существующих capabilities/guards. Pending submit/commerce lease/controlled host navigation сохраняются.
- «Мои средства» открывает существующие Активы со всем портфелем, не старый случайный account filter и не вторую независимую копию счетов. Счета доступны через существующее меню/размещения. Явный выбор счёта внутри Gold Accounts должен приводить к понятному отображению средств этого счёта в глубине, а не к невидимому выбору на постоянно общей Home.
- Шапка: бренд и поддержка слева, аватар профиля справа. Профиль и его возвраты не переделывать. Нижняя навигация остаётся Обзор/Активы/История/Меню.
- У Gold больше нет закреплений на Home, поэтому не оставлять в его Menu рабочую на вид настройку этих закреплений. Достаточно не передавать optional `homePins` из Gold host; общий Menu/Profile module и сохранённые pin preferences MONO не менять и не очищать.
- Один общий баланс с глазиком и подписью оценки; четыре действия с различимыми существующими SVG и подписями; одна строка «Мои средства»; компактный pending entry только при наличии/соответствующем resource состоянии. Никаких «Подробнее» в карточке, счётных табов, дополнительных account-kind балансов, «Мои счета» или разворачиваемого списка holdings на Home Gold.
- На Gold Home не выводить старую последнюю завершённую операцию и декоративный Promo, не заполнять пустоту рекламой. Эти компоненты, их материалы и отображение MONO сохраняются. График по умолчанию уже выключен — не менять существующие настройки/renderer этой задачей.
- Сохранить Gold-палитру, живой фон и namespace. Компактные качественные поверхности, читаемые суммы, без лишней рамки вокруг каждого текста. Существующий CSS/Motion, без новых dependencies/наборов иконок/редакторов.
- Motion: спокойный отклик press80–120ms, смена состояния около220ms, без overshoot/count-up/blur текста; reduced-motion показывает стабильное конечное состояние. Не менять существующий liquid ambient.
- Фокус видим; кнопки доступны клавиатурой, цели не меньше44px; возврат из Assets/accounts/receipt имеет живую цель после удаления старых tabs/launcher. Узкие320/390 и480px, без горизонтального overflow и закрытого нижней навигацией pending.
- Никаких серверных операций, preset writes, push, PR/merge, публикации или остановки прежних preview. ORACLE — единственный владелец новой локальной production build; после frozen/reviewed source он получает отдельный LOCALGO.
